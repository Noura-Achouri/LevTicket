# Submission Checklist

## Student information

- [ ] Student name added.
- [ ] Student ID added.
- [ ] University and department added.
- [ ] Supervisor name added.
- [ ] Submission date added.

## Paper preparation

- [ ] Read `FRONTEND_PAPER.md` and correct any project-specific wording.
- [ ] Add screenshots of the home page, search page, auction detail, ticket form, orders, and AI chat if required by the university.
- [ ] Add a system diagram if the teacher requires a visual diagram.
- [ ] Confirm which features were implemented personally and adjust the contribution wording.
- [ ] Add citations or course references required by the university format.

## Technical demonstration

- [ ] Confirm Node.js and npm are available.
- [ ] Run `npm install` in `frontend/`.
- [ ] Run `npm run build` successfully.
- [ ] Start the backend if demonstrating live API workflows.
- [ ] Test the mock-data demonstration.
- [ ] Test the responsive layout in desktop and mobile widths.

## Honesty and scope

- [ ] Mark backend-dependent features clearly during the presentation.
- [ ] Explain that the frontend currently has no dedicated automated test suite.
- [ ] Explain the difference between implemented AI interface controls and backend AI behavior.
- [ ] Do not present placeholder metrics on the home page as measured production statistics unless they are verified by the project team.
