# LevTicket Frontend Submission

This folder contains the frontend documentation prepared for the university final-project review.

## Reading order

1. [Frontend Paper](FRONTEND_PAPER.md) - the main academic document.
2. [Architecture and API Appendix](ARCHITECTURE_AND_API.md) - technical structure and backend integration.
3. [User Flows](USER_FLOWS.md) - the main user journeys and screen responsibilities.
4. [Setup and Verification](SETUP_AND_VERIFICATION.md) - how to run, configure, and verify the frontend.
5. [Submission Checklist](SUBMISSION_CHECKLIST.md) - material to complete before handing the project to the teacher.

## Project location

The implemented frontend is located in `frontend/` at the repository root.

## Important note

This documentation describes the current repository implementation. Some screens require the LevTicket backend at `http://localhost:8080`. The frontend also contains a mock-data mode for selected ticket and user experiences, controlled by `VITE_USE_MOCKS=true`.
